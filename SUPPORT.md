# Support Wahtuh Pho

Wahtuh Pho is an independent open-source project built by one developer using OpenCode, an Android phone with Termux, and rented/credited cloud compute when available. I do not currently have a dedicated workstation.

If you find the project useful and want to help me keep building open-source tools, voluntary support helps pay for compute, test devices, model experiments, and time spent fixing bugs.

## What support helps fund

- A reliable development workstation and Android test devices.
- Compute and storage for speech-recognition and code-switching experiments.
- Reproducible benchmarks, crash fixes, and accessibility testing.
- More open-source utilities built in public.

## Other ways to help

- Install the APK and report your Android version, device, steps to reproduce, and logs for any issue.
- Open a focused bug report or feature request.
- Star the repository, share it with people who might use offline-first dictation, or contribute a patch.
- Tell me which languages and real-world dictation workflows matter most to you.

Support is appreciated, but testing feedback is valuable too. Wahtuh Pho is early software; please review the known limitations in the README before relying on it for important dictation.
